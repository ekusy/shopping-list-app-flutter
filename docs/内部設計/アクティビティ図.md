# アクティビティ図

このドキュメントは、[ユースケース.md](./ユースケース.md) の各 UC について「処理の概要」を
アクティビティ図（mermaid `flowchart`）で示す。1 UC = 1 図を原則とし、入力バリデーション →
コントローラ（`presentation/providers/`）→ リポジトリ（`data/repositories/`）→ Firestore /
Cloud Functions までの分岐とエラーコードを俯瞰できるようにする。

- 静的なレイヤー構造は [アーキテクチャ概要.md](./アーキテクチャ概要.md)、動的なデータの動きは
  [データフロー.md](./データフロー.md)、状態の遷移は [状態遷移.md](./状態遷移.md) を参照。
- エラーコード（`AppErrorCode`）の一覧は [エラー仕様.md](../外部仕様/エラー仕様.md) を参照。

## 凡例

```mermaid
flowchart TD
    S([開始 / 終了]) --> A[処理・アクション]
    A --> Q{分岐条件}
    Q -->|条件成立| B[処理]
    Q -->|失敗| ERR([エラー終了<br/>AppErrorCode]):::err
    B --> E([終了])
    classDef err stroke-dasharray: 4 3
```

- **角丸（stadium）** = 開始 / 終了。
- **長方形** = 処理。ノード内に主要実装エントリ（メソッド名）を併記する。
- **ひし形** = 分岐（バリデーション / ガード）。
- **破線枠の終了** = `AppError` を throw して終わる経路（UI はトースト or インライン表示）。
- 書き込み系 UC の **一覧反映は `snapshots()` 購読** 経由で自動再描画される（図では「（snapshots で再描画）」と注記）。詳細は [データフロー (a)](./データフロー.md#a-snapshots-双方向購読)。

## 1. 認証（Epic-00）

### UC-A1 サインアップ

```mermaid
flowchart TD
    S([開始]) --> IN[メール / パスワード /\n確認用 / 表示名を入力]
    IN --> V1{パスワード空?}
    V1 -->|空| E1([auth.error.empty_password]):::err
    V1 -->|可| V2{確認用と不一致?}
    V2 -->|不一致| E2([auth.error.passwords_do_not_match]):::err
    V2 -->|一致| C[AuthController.signup]
    C --> SU[FirebaseAuthRepository.signUp]
    SU --> SUQ{Auth 例外?}
    SUQ -->|email-already-in-use 等| E3([auth.error.* インライン]):::err
    SUQ -->|成功| DOC[UserRepository.createUserDocument]
    DOC --> DN{表示名あり?}
    DN -->|あり| UP[updateUserProfile]
    DN -->|なし| OK
    UP --> OK[authStateChanges が user を発火]
    OK --> RT[_RouterNotifier が / へ遷移]
    RT --> E([終了])
    classDef err stroke-dasharray: 4 3
```

### UC-A2 ログイン

```mermaid
flowchart TD
    S([開始]) --> IN[メール / パスワード入力]
    IN --> C[AuthController.login → FirebaseAuthRepository.signIn]
    C --> Q{Auth 例外?}
    Q -->|invalid-credential| E1([auth.error.invalid_credential]):::err
    Q -->|too-many-requests| E2([auth.error.too_many_requests]):::err
    Q -->|成功| OK[authStateChanges が user を発火]
    OK --> RT[_RouterNotifier が認証状態を再評価 → /]
    RT --> E([終了])
    classDef err stroke-dasharray: 4 3
```

> `user-not-found` / `wrong-password` は SDK 統合により `invalid-credential` に寄せられる（[エラー仕様 §1](../外部仕様/エラー仕様.md#1-認証エラーapperror-経由)）。

### UC-A3 ログアウト

    C --> OK[authStateChanges が null を発火]
    OK --> RT[_RouterNotifier が /login へ]

### UC-A4 プロフィール編集
